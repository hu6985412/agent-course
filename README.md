# Agent 开发实战 16 周

> 面向 PHP 工程师的 Agent 开发通关记录。每周一个可运行的项目，从手搓循环到生产上线。

## 这个系列是什么

不是又一份「AI 速成清单」。这是一份**面向 PHP / 后端工程师**的 Agent 开发实录：用周次制节奏，把 Agent 从"能调 API"一步步做到"能上线"，每周一个可运行的项目。

每周交付：

- **一篇长文** —— 讲清楚这周的核心概念、为什么这么设计、我踩了什么坑（同步发知乎）
- **一份可运行代码** —— clone 下来配好 key 就能跑，不是伪代码
- **一张验收清单** —— 这周跑通了什么、没跑通什么，如实记录

## 适合谁

| 你是 | 收获 |
|---|---|
| **PHP / Java / Go 后端想转 AI 工程** | 最大的痛点是"学完 Python 才能开始"—— 这个系列给的是**双轨路径**：PHP 保持落地产出，Python 学新范式，不用停下来补课 |

## 为什么 PHP 开发者要单独写一份

2026 年，Laravel 13 已经把官方 `laravel/ai` SDK 推到生产稳定，底层是 Prism PHP：Agent 类、工具调用、对话持久化、队列异步、SSE 流式、多供应商故障转移、测试打桩——全是标准 Laravel 语法。

**你不需要先成为 Python 专家。** 你需要的只是把已有的工程能力（事务、幂等、权限、队列、测试）迁移到 Agent 这个新领域上。而这恰恰是很多 AI 教程不讲、但决定项目生死的部分。

## 技术选型

| 层 | 选择 | 理由 |
|---|---|---|
| 业务落地 | `laravel/ai` + Prism PHP（PHP） | 直接在已有系统里跑，复用队列与权限体系 |
| 编排思想 | LangGraph（Python） | 2026 年生产事实标准，学它其他框架都是子集 |
| 工具协议 | MCP（FastMCP） | 跨平台标准，一次写好处处可用 |
| 向量检索 | pgvector | 会 SQL 就上手，混合检索直接写 SQL |
| 评测观测 | Langfuse + 自建测试集 | 开源可自托管 |

选型的完整对比和踩坑记录见 [第 1 周](week-01/README.md) 附录。

## 贯穿全程的毕业项目

不是玩具 demo，是一个有真实复杂度的场景：**上市公司财报与可转债分析 Agent**

上传年报/季报 PDF、交易所 Excel 或财报截图，Agent 自动识别公司与报告期、抽取三大报表科目、归一化到标准科目字典后入库；之后用自然语言问「茅台 2025 年营收多少」「毛利率最近 5 年趋势」「这家公司资产负债率在同业什么水平」，Agent 基于真实入库数据回答并画图；进阶能力是财务比率计算、财务健康度分析，以及可转债指标（转股溢价率 / 纯债溢价率 / YTM / 强赎下修条款）。

**为什么选它**：

| 特征 | 说明 |
|---|---|
| 数据全部公开 | 巨潮资讯、交易所、akshare 接口，读者能复现，代码可开源 |
| 归一化有真陷阱 | 「归母净利润」与「扣非归母净利润」字面相似度 0.9+ 却是两个科目 —— 讲透"什么时候不该用向量检索"的最佳素材 |
| 时序天然 | 5 年 20 个报告期，趋势图、同比、同业对比全都有 |
| 解析有难度 | 财报 PDF 表格密集、跨页、合并单元格，比通用 PDF 难一个档次 |
| 合规能公开讲 | 「不构成投资建议」的红线设计可以逐条写进文章讨论 |

- W02 做科目抽取 → W03-04 做工具与循环 → W05-06 做科目归一化 → W07 啃财报 PDF 解析
- W09 做 MVP 闭环 → W13 建评测集 → W15 做合规红队 → W16 完整上线并接入可转债模块

> 完整设计（数据模型、工具清单、归一化策略、合规红线）将随 W09（MVP）与 W16（完整版）周次逐步展开，各周文章会给出对应的表结构与实现，不在开篇一次性放出。

> 项目数据源建议：`pip install akshare`，巨潮资讯网下载年报 PDF。W9 MVP 用接口取结构化数据先把链路跑通，W16 再啃 PDF 解析。

## 使用方式

```bash
git clone https://github.com/<你的账号>/agent-dev-16weeks.git
cd agent-dev-16weeks

uv venv .venv && .venv\Scripts\activate     # Windows
uv pip install openai python-dotenv rich

cp .env.example .env                        # 填入 API Key
cd week-01 && cat README.md                 # 读正文
cd code && python main.py                   # 跑代码
```

整个仓库共用一个虚拟环境，不必每周重建。前 8 周的代码互相独立，第 9 周起会复用前面的模块。

## 前置要求

- 任一后端语言的工程经验（示例以 PHP/Laravel 与 Python 双版本给出）
- 会 SQL
- Python 能读懂基础语法即可，边做边补
