# 云笔记 SaaS 产品手册

## 一、账户与登录

本产品支持邮箱注册与手机号注册两种方式。首次登录后系统会引导您创建第一个笔记本。若忘记密码，可通过注册邮箱重置，重置链接有效期为 30 分钟。企业版用户支持单点登录（SSO），管理员在后台配置好 SAML 元数据后即可启用。

## 二、退款政策

用户在购买会员套餐后的 7 天内，若未使用任何付费功能，可申请无理由全额退款。超过 7 天的，按已使用天数比例退还剩余费用。退款申请提交后，我们将在 1 至 3 个工作日内完成审核。审核通过后，款项将原路返回至您的支付账户：微信支付通常即时到账，支付宝需 1 至 2 个工作日，银行卡退款需 3 至 7 个工作日。若超过上述时限仍未到账，请联系在线客服并请提供订单编号与支付流水号以便核查。需要特别注意的是，使用平台优惠券抵扣的订单，优惠金额部分不予退还，仅退还您实际支付的现金金额。企业批量采购且发票已开具的订单，须先寄回纸质发票方可办理退款。若订单涉及第三方服务（如短信通道、云存储扩容包），该部分成本已从服务商处扣减，退款时将予以对应扣除，不计入可退金额。

会员套餐分为月度、年度两种。年度套餐相比月度可节省约两个月费用，但年度套餐的退款按未使用月份比例计算，已享受的折扣不退还。升级套餐（如从月度升年度）时，系统会按差价补款，不触发新的退款周期。

## 三、发票申请

会员付费完成后，可在「账户 - 发票管理」中申请增值税普通发票或专用发票。电子发票通常在申请通过后 24 小时内发送到预留邮箱。专用发票需填写正确的税号与开户行信息，审核周期为 3 至 5 个工作日。发票金额以实际支付金额为准，优惠抵扣部分不计入开票金额。

## 四、数据导出 API

高级会员可通过开放 API 导出笔记数据。示例如下：

```http
POST /api/v1/notes/export
Authorization: Bearer <your_token>
Content-Type: application/json

{
  "format": "markdown",
  "notebook_id": "nb_123",
  "include_attachments": true
}
```

返回为 ZIP 压缩包，单个笔记本最大支持 500 MB 附件。免费会员仅支持网页端手动导出，不支持 API。

## 五、会员等级

会员分为免费、标准、高级三档。标准会员可创建最多 50 个笔记本，高级会员无数量限制并享有 API 导出与团队协作权限。团队版按席位计费，管理员可集中管理成员权限与存储配额。
